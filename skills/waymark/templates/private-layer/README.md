# ~/.waymark — private layer

This user's memory of Waymark. The same for every agent, never published, never overwritten by installs or updates. Everything here **fills itself** as the user works (waymark `references/project-detection.md` and `references/learning.md`).

| File | What | Filled by |
|---|---|---|
| `agent.md` | skills folder and instructions file of each agent on this machine | installer |
| `profile.md` | stacks, package managers, architectures used | project detection |
| `preferences.md` | how to communicate and deliver | user corrections |
| `subagents.md` | search and delegation rules | experience |
| `projects.md` | index of projects and how they relate | first task in each project |
| `projects/<slug>.md` | before 2.0 only: the project memory, now `<project>/.waymark/memory.md` (a `Moved:` stub stays after migration) | — |
| `learnings/dept-<dept>.md` | lessons seen once (staging) | learning loop |
| `coexistence.md` | only with another agent framework: who leads, its rules Waymark adopts, uses as fallback or resolves | installer and updates |

To use it on several machines, keep it in a **private** repository.
